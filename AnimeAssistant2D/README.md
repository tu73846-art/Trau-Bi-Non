# Anime Assistant 2D

Android 5.0+ (API 21+), source prototype. The app provides a draggable overlay bubble, a small chat panel, male/female labels, and Android TextToSpeech in Vietnamese when a Vietnamese voice is installed.

The chat currently echoes text in a toast; it is not connected to an AI service. Character artwork and full animation are not included.

Build output is generated by GitHub Actions as a debug APK.
